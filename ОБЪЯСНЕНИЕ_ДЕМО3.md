# Что это за игра

**Battle Arena** — пошаговая боевая игра для двух армий. Каждая армия —
коллекция юнитов, которые по очереди обмениваются ударами и применяют
способности. Цель — уничтожить армию противника.

* Платформа: **.NET 8 / C#**
* Запуск: `dotnet run` в каталоге `BattleGame/`
* Главное меню: новая игра / загрузить / выход
* Внутри игры: ход, авто-бой, перепостроение, Undo/Redo, сохранение

В рамках курса игра используется как площадка для демонстрации **паттернов
проектирования** и принципов **SOLID**. К 3-му демо добавлены 4 новых паттерна.

# Что доработано к 3-му демо (главное)

## 1. Удалён старый Proxy

Со 2-го демо были два прокси:

* `UnitProxy` — щит, перехватывающий урон.
* `SoundLoggerProxy` — обёртка логгера со звуком при смерти.

Оба удалены — задание Юлии: «убираем старый прокси, вместо двух прокси —
2 наблюдателя». Их заменил **Observer**.

## 2. Observer — два наблюдателя

Реализованы **без** `event` (требование лекции — «не использовать ивенты»).
Классическая GoF-схема: `Battlefield` хранит `List<IBattleObserver>`,
вызывает `Notify*` методы.

**Интерфейс наблюдателя** (`Interfaces/IBattleObserver.cs`):

```csharp
public interface IBattleObserver
{
    void OnDamage(Unit target, Army army, int damage, int hpBefore);
    void OnDeath(Unit unit, Army army);
    void OnTurnStarted(int turnNumber);
}
```

**`DeathObserver`** — реагирует только на смерть, делегирует логгеру и ведёт
счёт потерь по армиям. Заменяет звуковой прокси.

```csharp
public void OnDeath(Unit unit, Army army)
{
    _logger.UnitDied(unit, army.Name);
    if (_deathCount.ContainsKey(army.Name))
        _deathCount[army.Name]++;
    else
        _deathCount[army.Name] = 1;
}
```

**`DamageObserver`** — копит урон за ход и считает «статичные» ходы.
Если 10 ходов подряд никто не получил урон — игра в патовой ситуации
(требование «upd по гуляй-город»: ничья после 10 ходов без изменений HP).

```csharp
public bool IsDraw => _staticTurns >= DrawAfterStaticTurns; // 10

public void OnDamage(Unit target, Army army, int damage, int hpBefore)
{
    if (damage > 0) _damageThisTurn += damage;
}

public void OnTurnStarted(int turnNumber)
{
    if (turnNumber <= 1) { _damageThisTurn = 0; return; }
    if (_damageThisTurn == 0) _staticTurns++;
    else _staticTurns = 0;
    _damageThisTurn = 0;
}
```

**Подписка** в `Battlefield`:

```csharp
public void Subscribe(IBattleObserver observer)
{
    if (!_observers.Contains(observer))
        _observers.Add(observer);
    if (observer is DamageObserver d) DamageObserver = d;
}

public void NotifyDamage(Unit unit, Army army, int dmg, int hpBefore)
{
    foreach (var o in _observers) o.OnDamage(unit, army, dmg, hpBefore);
}
```

В `Program.cs` оба подписываются при старте игры:

```csharp
bf.Subscribe(new DeathObserver(logger));   // 1-й — смерть
bf.Subscribe(new DamageObserver());        // 2-й — урон + ничья
```

## 3. Strategy — 3 режима боя со сменой в любой момент

**Интерфейс** (`Interfaces/IBattleStrategy.cs`):

```csharp
public interface IBattleStrategy
{
    string Name { get; }
    string Description { get; }
    void ExecuteMelee(Battlefield battlefield);
}
```

**Три реализации** в `Services/Strategies/`:

| Класс | Поведение |
|---|---|
| `BridgeStrategy` | Узкий мост — 1 vs 1, бой только первых юнитов |
| `WideBridgeStrategy` | Широкий мост — колонна по трое, 1A↔1B, 2A↔2B, 3A↔3B |
| `WallStrategy` | Стенка на стенку — все слоты против всех |

**Пример — широкий мост (по трое):**

```csharp
public void ExecuteMelee(Battlefield bf)
{
    bf.Logger.PhaseHeader($"Ближний бой — {Name}");
    for (int slot = 0; slot < Width; slot++) // Width = 3
    {
        if (slot >= bf.Army1.Units.Count || slot >= bf.Army2.Units.Count) break;
        var attacker = bf.Army1.Units[slot];
        var defender = bf.Army2.Units[slot];
        if (!attacker.IsAlive || !defender.IsAlive) continue;
        // ...удар + ответный удар, нотификации Observer-у
    }
}
```

**Смена стратегии в любой момент** — в `Battlefield`:

```csharp
public void SetStrategy(IBattleStrategy strategy)
{
    Strategy = strategy;
    StrategyName = strategy.Name;
    Logger?.StrategyChanged(strategy.Name);
}
```

В меню — отдельный пункт **«5. Перепостроение (сменить стратегию)»**.
Сменить можно даже в середине партии.

**`StrategyResolver`** — резолвит стратегию по имени (нужно для загрузки
сейва и Undo, т.к. сам объект-стратегия не сериализуется):

```csharp
public static IBattleStrategy Resolve(string name)
{
    foreach (var s in All())
        if (s.Name == name) return s;
    return new BridgeStrategy();
}
```

## 4. Decorator — баффы оруженосца на тяжёлого

Лёгкий пехотинец получил роль **оруженосца**: рядом стоит тяжёлый —
оруженосец надевает на него один из 4 баффов. Каждый бафф — это
**декоратор**, оборачивающий юнит и добавляющий бонус.

| Бафф | ATK | DEF | Тэг |
|---|---|---|---|
| Конь (`HorseBuff`) | +6 | +4 | `Конь` |
| Копьё (`SpearBuff`) | +5 | 0 | `Копьё` |
| Щит (`ShieldBuff`) | 0 | +5 | `Щит` |
| Шлем (`HelmetBuff`) | 0 | +3 | `Шлем` |

**Базовый класс декоратора** (`Units/Buffs/UnitBuff.cs`):

```csharp
public abstract class UnitBuff : Unit
{
    public Unit Inner { get; set; } = null!;
    public abstract string BuffName { get; }
    public virtual int BonusDamage => 0;
    public virtual int BonusDefense => 0;

    // Все характеристики делегируются Inner с прибавкой бонуса
    public override int Damage  { get => Inner.Damage  + BonusDamage;  ... }
    public override int Defense { get => Inner.Defense + BonusDefense; ... }
    public override int Health  { get => Inner.Health;  set => Inner.Health = value; }

    // Урон уходит во внутренний юнит (полиморфно через цепочку)
    public override void TakeDamage(int damage) => Inner.TakeDamage(damage);
}
```

**Конкретный бафф (Конь):**

```csharp
public class HorseBuff : UnitBuff
{
    public const int Atk = 6, Def = 4;
    public override string BuffName => "Конь";
    public override int BonusDamage  => Atk;
    public override int BonusDefense => Def;
    public HorseBuff(Unit inner) : base(inner) { }
}
```

**Логика навешивания** (`Battlefield.ProcessSquire`):

```csharp
private void ProcessSquire(LightInfantry squire, Army allies, int squireIndex)
{
    if (Rng.Next(100) >= squire.BuffChance) return;     // не повезло

    for (int delta = -squire.Range; delta <= squire.Range; delta++)
    {
        if (delta == 0) continue;
        int j = squireIndex + delta;
        if (j < 0 || j >= allies.Units.Count) continue;

        var neighbor = allies.Units[j];
        if (UnitBuff.Unwrap(neighbor) is not HeavyInfantry) continue;

        // Один и тот же бафф не вешаем дважды
        var slots = new[]{ HorseBuff.Tag, SpearBuff.Tag, ShieldBuff.Tag, HelmetBuff.Tag }
                    .Where(b => !UnitBuff.HasBuff(neighbor, b)).ToList();
        if (slots.Count == 0) continue;

        string chosen = slots[Rng.Next(slots.Count)];
        Unit decorated = chosen switch
        {
            "Конь"  => new HorseBuff(neighbor),
            "Копьё" => new SpearBuff(neighbor),
            "Щит"   => new ShieldBuff(neighbor),
            _       => new HelmetBuff(neighbor),
        };
        allies.Units[j] = decorated;
        Logger.BuffApplied(allies.Units[squireIndex], decorated, chosen);
        return;
    }
}
```

**Сбитие баффа от сильного удара** (`Battlefield.StripBuffsOnHardHits`):
если HP опустился ниже 50% от максимума — 30%-й шанс сорвать верхний бафф.

```csharp
if (u.Health * 2 >= u.MaxHealth) continue;   // не критично
if (Rng.Next(100) >= 30) continue;           // не повезло
army.Units[i] = topBuff.Inner;               // снимаем верхний бафф
Logger.BuffStripped(army.Units[i], topBuff.BuffName);
```

## 5. Command — Undo / Redo / Reset

Каждый пункт меню — это **команда**. История команд хранится в `CommandManager`.

**Интерфейс:**

```csharp
public interface ICommand
{
    string Description { get; }
    void Execute();
    void Undo();
}
```

**Реализованные команды:**

| Команда | Что делает | Как откатывается |
|---|---|---|
| `MakeTurnCommand` | Один ход | Snapshot → Restore |
| `PlayToEndCommand` | Авто-бой до конца | Snapshot → Restore (1 откат на всё) |
| `ChangeStrategyCommand` | Смена стратегии | Возвращает прошлую стратегию |

**`MakeTurnCommand`** — Memento на JSON-снапшоте Battlefield:

```csharp
public void Execute()
{
    _snapshot = _bf.Snapshot();   // JSON всего поля
    _bf.MakeTurn();
}

public void Undo()
{
    _bf.Restore(_snapshot);
    _bf.SetStrategy(StrategyResolver.Resolve(_bf.StrategyName));
    _damageObs?.Reset();
}
```

**`CommandManager`** — два стека: история и redo:

```csharp
public void Execute(ICommand cmd)
{
    cmd.Execute();
    _history.Push(cmd);
    _redo.Clear();
}

public bool Undo()
{
    if (!CanUndo) return false;
    var cmd = _history.Pop();
    cmd.Undo();
    _redo.Push(cmd);
    return true;
}

public bool Redo()
{
    if (!CanRedo) return false;
    var cmd = _redo.Pop();
    cmd.Execute();
    _history.Push(cmd);
    return true;
}

// "Сброс к началу" — много раз Undo подряд
public void Reset() { while (CanUndo) Undo(); }
```

**Snapshot/Restore в Battlefield** — Memento:

```csharp
public string Snapshot() => JsonSerializer.Serialize(this, SnapOpts);

public void Restore(string snapshot)
{
    var restored = JsonSerializer.Deserialize<Battlefield>(snapshot, SnapOpts);
    if (restored == null) return;
    Army1 = restored.Army1;
    Army2 = restored.Army2;
    TurnNumber = restored.TurnNumber;
    StrategyName = restored.StrategyName;
}
```

## 6. Ничья по 10 ходам без изменений HP

Реализована через `DamageObserver.IsDraw`. `Battlefield` учитывает её
в `IsGameOver`:

```csharp
public bool IsGameOver =>
    Army1.IsDefeated || Army2.IsDefeated
    || (DamageObserver?.IsDraw ?? false);

private void AnnounceEnd()
{
    if (DamageObserver?.IsDraw == true && !Army1.IsDefeated && !Army2.IsDefeated)
    {
        Logger.Draw("10 ходов без изменений HP — пат.");
        return;
    }
    Logger.GameOver(GetWinner());
}
```

## 7. Маг — защита вероятности клонирования

После случайной вариации `CloneChance` мог формально выйти за `[0..100]`.
Сделан кламп:

```csharp
int chance = Math.Max(0, Math.Min(100, wizard.CloneChance));
if (Rng.Next(100) >= chance) { Logger.CloneFailed(...); return; }
```

# Новое игровое меню

```
--- Игровое меню (построение: <текущая стратегия>) ---
1. Сделать ход
2. Играть до конца
3. Показать армии
4. Сохранить игру
5. Перепостроение (сменить стратегию)
6. Отменить (Undo)  [история: N]
7. Повторить (Redo)
8. Сбросить к началу (Reset)
0. Вернуться в главное меню
```

# SOLID — что усилилось к 3-му демо

| Принцип | Реализация |
|---|---|
| **S** Single Responsibility | Каждый Observer — одно событие. Каждая Strategy — один режим. Каждая Command — одна операция. |
| **O** Open/Closed | Новые стратегии / баффы / команды добавляются без изменения `Battlefield`. |
| **L** Liskov Substitution | `UnitBuff` полностью подменяет любого юнита. Стратегии взаимозаменяемы. |
| **I** Interface Segregation | `IBattleObserver`, `IBattleStrategy`, `ICommand` — узкие, без лишнего. |
| **D** Dependency Inversion | `Battlefield` зависит от интерфейсов (`IBattleStrategy`, `IBattleObserver`, `IBattleLogger`). |

# Что показывать на демо

1. **Запуск, новая игра** — собираются 2 армии по бюджету.
2. **Узкий мост** — обычный 1v1 ход (как было в демо 2).
3. **Перепостроение** — пункт 5, переключиться на «широкий мост».
   Юлия просила: «перепостроение в любой момент игры». Срабатывает на лету.
4. **Декоратор-баффы** — навести лёгких рядом с тяжёлым, сделать ход:
   `A1:Лёгкий#2 -> надел [Конь] на A1:Тяжёлый#1`. У тяжёлого
   `ATK: 26, DEF: 19` (было 20/15).
5. **Observer (смерть)** — в логе при гибели:
   `*** A2:Лёгкий#1 из Армия 2 погиб! ***` — это `DeathObserver`.
6. **Observer (урон / пат)** — теоретически работает после 10 ходов без HP.
7. **Undo / Redo** — пункты 6/7. После хода история = 1, Undo возвращает
   предыдущее состояние, Redo накатывает обратно.
8. **Reset** — пункт 8, отбрасывает к самому началу партии.
9. **Save/Load** — стратегия восстанавливается по имени.
